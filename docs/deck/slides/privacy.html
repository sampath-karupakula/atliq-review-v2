Masked before every AI call

  • Names of people and companies
  • Emails, phone numbers, street addresses
  • Tax, company, passport and Aadhaar numbers
  • Bank accounts, IBAN, SWIFT and routing codes
  • Medical record numbers, dates of birth
  • Web links, IP addresses, client and PO references

Then a leak check: if any original value is still in the text, the call is blocked. The masking key stays on the server.

AtliQ Review

8

Client contracts are full of personal and banking data. Before any text is sent to the model, code replaces it with tokens, and the answer is mapped back afterwards so the founder reads real names. Only the street is masked in an address, so the city and country still inform the legal analysis. A second pass, the leak check, looks for every original value in the outgoing text and blocks the call if one slipped through. Unmasked contract text is never written to logs. The name and address on this slide are made up for illustration.
