Runs in the background in 2–4 minutes, about $0.10 per review. If an AI answer fails its schema twice, the review stops with a plain message instead of showing half a report.

AtliQ Review

5

Eight steps, four of them pure code. Every AI step receives masked text only and returns JSON that is validated against a schema; one retry, then fail closed. The summary is written last, by the AI, from findings that code has already verified and scored, so the summary can’t claim something the findings don’t support. The review runs on the server with a lease and watchdog, so the user can close the page and it can be resumed after a connection error.
