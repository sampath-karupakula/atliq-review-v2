First review

A reviewer marks every finding agree, disagree or question. “Review done” unlocks only when all are marked.

The decision lock

No “Intend to sign” while a Serious item is open. Dismissing needs a reason; accepting a risk needs a note.

Counsel when needed

Questions go to outside counsel with an answer-by date. Counsel can answer, never decide.

The stage is worked out from what has happened, not set by hand. Each role (CEO, reviewer, counsel) gets its own dashboard.

The report is the start, not the end. A reviewer such as Bhavin does the first review; the founder can be asked for a quick decision. Rejecting as written moves the contract to Negotiating and turns the open items into a pushback list to copy into an email: the tool drafts, the person sends. Permissions are checked on the server for every action, so counsel’s account is refused even if someone calls the API directly. Deleting a contract always needs an admin’s approval, so nothing disappears silently.
