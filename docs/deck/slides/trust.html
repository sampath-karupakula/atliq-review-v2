Four rules that keep the report honest

A quote, or “Not sure”

Every finding carries the exact words and clause number. Code checks them against the contract; anything it can’t find goes to the Not sure tray.

Strict on Serious

Serious only when verified and irreversible, unbounded or a live clash. Bounded issues are Negotiable, and clean contracts score Low.

The contract is data

Text hidden in a contract that tells an AI what to do is reported as a finding and never obeyed.

Fail closed

If the AI’s answer doesn’t validate after one retry, the review stops with a plain message. A partial report is never shown as complete.

7

A founder will only act on the report if he can trust it, so trust is built in rather than promised. The quote rule is the most important: the model can’t invent a clause, because code looks for the exact words in the contract. In the full test run, 290 of 290 quotes were verbatim. One test contract hides a sentence telling AI reviewers to ignore the penalty clause; the tool reports the sentence and flags the penalty as Serious anyway.
