The app was built in fourteen phases, each on its own branch and merged by pull request only after CI was green: typecheck, lint, the unit tests, an evaluation gate that needs no AI, a migrate-and-seed of a real Postgres, a production build and a smoke test of the key pages and permission refusals. The features that need no AI were built first; the AI features came once the pipeline and data were solid. Production runs on Vercel with a Neon Postgres database.
