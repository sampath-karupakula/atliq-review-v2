The register is the tool’s memory, and it is what makes the clash check possible. Each promise is tied to its signed contract and clause, so a report links straight to it and back. Status is code: Orbit’s restriction ended in June 2025, so it shows as history, not a risk. Precedent labels stop the tool from learning bad habits: Brightwater’s uncapped penalty was signed from a phone with no redlines, and it is labelled “waved through” so it never shows up as “AtliQ accepted this before”.
